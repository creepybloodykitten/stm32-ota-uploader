# Дистанционное обновление прошивки STM32 с использованием общего хоста(например Raspberry pi 4) по SSH

Поддерживается обновление с usb подключением к хосту либо с uart соединением.
Программа разработана в Qt Creator с использованием MinGW64, поэтому для работоспособности программы требуется:

1)На хост поставить .py файлы из папки pi-controller и установить st-flash(для usb-режима) и stm32flash(по uart)
```
sudo apt install stlink-tools
sudo apt install stm32flash
```

2)Установить libssh на устройство с которого будут отправляться прошивки

3)В sshcontrol.h поменять константные пути на нужные

4)Собрать проект
